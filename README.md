# Pokédex Simples

App Flutter que consome a PokéAPI para buscar informações de Pokémon.

## API utilizada
- Nome: PokéAPI
- Endereço: https://pokeapi.co/api/v2/pokemon/{nome}

## Como executar
flutter pub get
flutter run

## Conceitos aplicados
Requisições HTTP, JSON, async/await e exibição de dados na interface.
